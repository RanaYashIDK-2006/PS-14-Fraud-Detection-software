  • Chronological split enforced — train < 2016 | validation 2016–17 | untouched test ≥ 2018; the legacy Month≤9 split (which pooled 26 years — 2020 in train, 1995 as "test") is retired
  • Feature parity verified — 11/11 native parity gates (48 features, |d|≤1e-9); load-time schema gate refuses incompatible artifacts

  • Phase-5 (post-integrity-fix): absent-merchant FPR is a training-coverage artifact, not a model failure — corrected merchant universe is 63,288 name-hash codes / 57,882 pre-2016-active (the earlier 99,602/98,138 came from a mis-hashed volume table, now fixed and validated). Verdict: OUTCOME B, E_hardneg kept deployed and untouched
  • Label latency UNVERIFIED — the IBM corpus is pre-labeled with no label-availability timestamp; the 3 label-dependent fraud-rate features keep UNVERIFIED status; count-only establishment signals are safe
